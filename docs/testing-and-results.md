# Testing and Results

The thesis describes verification and validation tests around the mobile application, including:

- invalid username/password handling;
- invalid or already registered email addresses;
- registration validation;
- blank-field handling;
- profile-selection validation.

The thesis reports these test cases as verified in the prototype.

## Demonstrated prototype behavior

The working-result chapter documents the complete data flow from collision sensors and sensor modules to the ESP8266, Firebase, and the Hadisa application. The application screenshots show authentication, registration, accident cards, accident records, map visualization, user profiles, and accident operation views.

## Scope note

These results represent an academic prototype. They do not constitute automotive safety certification, emergency-service certification, or a production validation study.
