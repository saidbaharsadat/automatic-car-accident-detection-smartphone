# Thesis Publication Note

The final thesis PDF contains historical development credentials inside source-code listings/screenshots. For that reason, the original PDF should not be published unchanged.

Recommended publication process:

1. Rotate any credential that may still be active.
2. Redact passwords, Wi-Fi credentials, Firebase user credentials, API keys where appropriate, and any personal contact information.
3. Export a redacted archival PDF.
4. Add the redacted PDF to `docs/` and link it from the main README.

The repository itself should use placeholders or local ignored configuration files for all secrets.
